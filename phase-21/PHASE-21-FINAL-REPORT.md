# Phase 21 final report

24 November 2026. **Overall verdict: PARTIAL.** Reproducible new firmware, tooling, Ghidra and cross-engine results were produced. Missing 14.10 and additional SCE/ABI 3 inputs leave explicit gaps. Protected firmware executable code remains unanalysed and jailbreak probability remains **UNKNOWN**.

1. **Acquisition:** downloaded and verified standard 14.20 (1,266,086,912 bytes) and recovery 14.22 (1,423,697,408 bytes). Reused/rehashed existing standard 14.22 (1,266,091,008 bytes). Standard 14.10's exact official object returned HTTP 200 /length 0, including a bounded GET; it was not substituted.
2. **Metadata:** 14.20→14.22 grows by 4,096 outer bytes and 4,128 entry bytes; zero padding reduces 419→387. Exactly 115 bytes differ in [0,0x440), with identical first 16 inner bytes. Recovery has two entries: its first matches standard 14.22's inner range by complete SHA-256; its second is 157,606,077 bytes with unknown protected content. This newly corroborates selected previously blocked/source-only claims without changing historical Phase 20 classifications.
3. **Utility:** original read-only `firmware_compare.py` streams full hashes, validates SLB2 v3 bounds/overlaps, measures padding and sampled distributions, compares explicit windows and emits terminal/JSON/CSV output. **27/27 tests pass**, covering malformed/truncated headers, invalid offsets/sizes, overlaps, multiple entries, window boundaries, JSON/CSV output and input/output aliases.
4. **Ghidra:** four new static imports in a separate project. Repaired baseline again resolves 165 external records across six libraries and applies **567/567** relocations; 8/8 sampled bodies decompile. New ABI 2 /ET_DYN homebrew correctly selects generic ELF, applying **20/20** relocations with 19 external records and 8/8 sampled bodies decompiled. FreeBSD ET_REL and linked System V ET_EXEC controls correctly select generic ELF, each decompiling 2/2 sampled functions. Additional SCE-positive, ABI 3 and alternate SCE-layout validation remains incomplete; baseline warnings are retained.
5. **Browsers:** original lightweight suite tested in Chromium 150.0.7871.181 and Firefox 140.15.0esr, two header modes each: **84/84 normal check results PASS**. Explicit wrong/missing header controls yield 1 FAIL /1 SKIP respectively and are counted separately. The portable harness replay reproduces all six summaries. No console or pressure test ran.
6. **Corrections:** HTTP 200 is not sufficient acquisition evidence; ABI 2 alone is not Prospero-loader compatibility; zero-input Atomics errors are expected by operation/type; sandbox isolation and standard messaging can coexist; encrypted-package differences do not identify a vulnerability fix. The linked control's System V output is not mislabelled a FreeBSD runtime executable.
7. **Evidence/preservation:** all required reports/tools/tests/CSVs and machine-readable results are provided. Firmware and prior Phase 20/notes hashes remain intact; new work uses new directories and projects. No software reinstall was needed. See README for the objective grades and integrity instructions.

Phase 21 is prepared on `phase21-technical-validation-20261124`, based on Phase 20 head `91e3fa2ee5f71b34b6453736837003316254b216`, preserving Phases 1–20. 9. **Remaining blockers:** authentic nonempty historical 14.10, genuine additional eligible ABI 2/ABI 3 SCE samples, alternate dynlib layouts, lawful plaintext retail inputs and controlled hardware evidence. The latter are not prerequisites for these desktop/container checks and were not fabricated.
