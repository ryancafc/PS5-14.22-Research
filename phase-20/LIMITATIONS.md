# Limitations and interpretation rules

1. This audit was performed on incorporated repository snapshots. The auditor is the same assistant workflow that created the earlier local setup; fresh checks are not an independent human/laboratory replication. Eleven claim units are labelled Independently verified because new, independently authored measurements or primary-source checks corroborated external assertions. Four desktop reproductions remain a separate category.
2. No PS5 console test, exploit/payload execution, privileged third-party script, key search, firmware decryption or firmware installation occurred. Exploit-related code was inspected only enough to establish inputs, simulation boundaries and metric accounting.
3. No plaintext retail 14.22 executable is available. Older 13.60 kernel reports and public source defaults cannot establish deployed 14.22 behavior. The 165-import/567-relocation Ghidra statuses were reviewed from saved evidence, not rerun; the fresh ELF decoder independently checked header, library and relocation-type facts.
4. Recovery and older update packages, older kernel/reference dumps, game inputs and named raw comparison logs are absent. Their reported results were not fabricated or replaced by a mock result.
5. The desktop checks used one Chromium build. No aggressive allocation mode or pressure ceiling was measured. A false diagnostic expectation can be contradicted without running the destabilising modes.
6. Shared magic, visible header fields, entropy, source-code patterns, user-agent tokens and absent NVD platform listings have bounded evidentiary meaning. None alone proves decryption, a particular fix, identical protection or retail exploitability.
7. Claim classes are exclusive primary labels. Source-supported means supported by inspected source, not by hardware execution. Simulation only does not mean retail reproduction. Author-reported does not imply fraud or falsity. Blocked identifies a specific missing prerequisite. Contradicted applies only to the stated bounded expectation or accounting claim.
8. The registers paraphrase significant selected claims; they are not an exhaustive validation of all research, code or external links. Source lines locate the reviewed assertion or relevant implementation. Changes upstream after the pinned commits are outside this audit.
9. No complete proprietary package, game, system executable, console dump, protected key, development TLS key, trigger ELF or executable exploitation implementation is included in the publication. B's unlicensed HTML is not redistributed. Inventory hashes and public source links are not a licence attestation for every byte in an upstream repository.
10. Jailbreak probability remains UNKNOWN. A's 5–10 percent statement has no defined population, calibration model or measured outcome distribution. Commit activity and passing mock stages do not estimate exploitability.
